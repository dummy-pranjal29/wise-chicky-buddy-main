# Wise Chicky

Wise Chicky is a preventive child mental health and development app for Indian parents. It combines parent, teacher, and child assessments with expert session booking, resources, and a Super Parent AI concept.

## Stack

- Vite + React + TypeScript
- Tailwind CSS + shadcn/ui
- Supabase for authentication and user profile persistence
- Vitest for tests

## Run locally

PowerShell can block `npm.ps1` on some Windows machines. To avoid that launcher issue, run the app directly with Node:

```bash
node scripts/dev-server.mjs
```

On Windows, you can also use:

```bat
run-dev.cmd
```
